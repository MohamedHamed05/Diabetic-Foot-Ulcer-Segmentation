# DiaMate Diabetic Foot Ulcer Segmentation

DiaMate Ulcer API is a semantic segmentation service built on a U-Net trained from scratch to detect diabetic foot ulcers in smartphone camera images. It accepts a photo of a foot wound and returns a binary mask identifying the ulcer region alongside a highlighted overlay image and ulcer coverage statistics.
 
The API was developed as part of the DiaMate graduation project at Benha Faculty of Computers and Artificial Intelligence (BFCAI), Benha University, aimed at bringing AI-assisted wound assessment to the Egyptian healthcare context.
